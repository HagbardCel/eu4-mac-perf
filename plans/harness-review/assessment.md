## Findings in priority order

### 1. Verified · high · qualification changes meaning between interfaces

On `tests.test_m7_diagnosis.DiagnosisFixture`, change the blue channel of one final pixel by one and retain exact intermediates. The default policy yields `qualified_difference`. Passing a policy with max channel error 1, mismatched fraction 1 and mean error 1 yields **`qualified_match`, qualified true**, although the returned statistics still show **1 mismatched pixel, max error 1**. This used the actual `diagnose_frame` path. `final_comparison_report` maps any policy pass to pixel “match.” The shipped M6 policy uses zero thresholds. The experiment establishes a defect in exact qualification with an override, not a defect in the pilot's zero-threshold statistics. Keep policy-based evaluation for callers that ask for it, and require raw zero statistics for every exact claim. The independent correction check already recomputes raw metrics and checks required intermediates, producer binding and regression inventory. ### 4. Verified · high · the shader translation and sampler caches conflate different effective inputs

- `m6_frame._shader_source_identity` groups program names and stage-source hashes. Swapping the two captured attribute locations in a copy of draw 14 leaves its key identical. `gfx_shader_translate.translate_trace` collects those locations and `translate_stage` injects them into compiler input. The translator also injects linked varying locations, but stage output filenames contain only the original source SHA and stage. On 616 the 17 programs reference 33 distinct MSL filenames, one shared, with no differing maps for that shared filename. The contract collision is demonstrated; a wrong image from this collision on 616 is unproved. Fix keys at the actual compiler input and audit runtime shader lookup too. ## Renderer boundary and remaining verification

In the active design, original GL remains authoritative. Capture runs inside the game, seals ordered logical state/resources and reference pixels, and the injected Metal shadow consumes that captured work in the same EU4 process. An external coordinator prepares/diagnoses the result. The independent executable replays sealed inputs offline through the same correctness core.
