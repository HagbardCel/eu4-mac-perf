# 02 · Establish whether captured inputs reproduce the GL reference

**Objective and scope.** Diagnose the first terrain draw using original live GL, a bounded original-API draw control, and Metal. Deliver an exact comparison and a supported-input contract. The existing one-process shadow and sealed original reference remain the authority. This is an investigation with a valid negative outcome. An authentic correction is conditional on identifying a cause.

**Starting evidence.** Use 616 as the failing target, 611 and 916 as separate reproductions. Each frame has its own seal and checkpoint request. The FBO control on 916 gives 885/3 vs live at checkpoint 15. A later compressed-input experiment gives 9/1, and the window control has >1.4M alpha mismatches. Candidate `34158764` subsequently captured actual blocks on present 904; checkpoint 15 is 4/1 and 16 is 3,602/119. The 904 compressed GL control for draw 15 already returned 4,645/86 vs live at observation 16. Start with its manifest, verify depth history, and avoid an identical rerun. Its 916 DDS-injected Metal result was 3/1 and 3,151/47. All-three-way exact equality remains open. Existing transfer control validates captured copies and intervening lifetimes. The pilot builder assumes unsigned-short indices and clears depth; direct promotion would silently accept unsupported draws. [Assessment and source evidence](../assessment.md) · [existing transfer validation](../../../automation/gfx_gl_control.py) · prototype (`artifacts/m7-pilot-event16/evidence/build_manifest.py`)

**Design and order**

1. Resolve and verify the case. Select observation by session, capture frame, stream digest, resource/generation and pre-event ordinal. Derive the writer and prior seed from the graph. Require the same resource and a valid preceding state, with clear or prefix evidence for depth/stencil and color. Use 616 to reproduce the original failing attribution. Use 904 to test original compressed bytes on draw 14/checkpoint 15. On draw 15, reconstruct the already-executed depth prefix or stop with missing depth evidence. A live color seed combined with an arbitrary depth clear cannot qualify. Validate reported full-frame or local single-draw scope separately.
2. Add a selected-draw diagnostic beside `gfx_gl_control`, exposed through the existing `eu4_replay`/diagnosis interface. Reuse frame verification, graph, checkpoint reconciliation and pixel comparator. Consume referenced immutable blobs directly; avoid copying a full blob tree per manifest. Adapt the small GL host behind capability checks for the proven triangle-indexed, typed attribute, uniform and 2D texture subset. Derive sampler units, clamp values, normalization, draw mode/count, stride/range, blend/scissor/cull, depth prestate, viewport, target format/sample count and color space from evidence. Unknown active state is explicit. Enforce input size/count limits; write only to a fresh experiment output. Verify source hashes and compile/link receipts.
3. For each pair record image digest, layout (including alpha/origin), all-channel exact stats, producer digest, effective inputs, seed, and which state is missing. Invalid identities, readback, dimensions, GPU failures and unsupported states precede any inference. GL control vs live exact and Metal vs live different localizes a renderer-side candidate for this input. If control and Metal are exactly equal but both differ from live, investigate shared inputs or target representation. If all three differ, report all three numbers and leave causation open. Diagnostic controls cannot advance the verified cursor. Test on 611/916 independently, even where program and ordinal coincide.
4. Before live work, inspect the latest `R/experiments/gl-comp-*-event14-b` manifests and compare all four channels. Bind each of the eight substituted units (0/4/9/10/15/13/2/3) to exact level bytes, target, raw internal enum, block format and provenance. Game-file DDS candidates and matching dimensions are weaker than a captured live digest. A synthetic colored BC1/BC2/BC3 block/mip fixture should contrast original blocks with decoded/reuploaded bytes on GL, including odd dimensions and alpha. Hold shader, seed, sampler and drawable fixed. Use the authentic compressed levels from 904; rerun this case with the decoded representation as a recorded diagnostic variant and with the original blocks. Reconcile `34158764` before writing any new recorder/backend code. Its `compressed_levels` returns false on a partial chain and silently selects decoded. Distinguish legacy all-decoded, complete supported block chain, partial/mixed and unsupported. Preserve raw internal enum, validate expected block pitch/size per level and test BC1 RGB/alpha semantics. Reuse any newer same-seal paired results before repeating them. Only for an independently identified missing observable prepare *one* guarded observation of selected compressed levels and drawable/depth/sample descriptors, with bounded byte budget, GL state restoration and cache invalidation. Use the existing writer and sealing paths. Never reconstruct compressed bytes by recompressing RGBA.
5. Only after this evidence, compare the same original blocks in GL and a supported Metal format; record capability failures on the actual device. Apply any cohesive Metal migration via the existing reconstruction campaign/skill and independent checker. Repeat the relevant controlled replay A/B/A with exact earlier checkpoints and a protected independent control. A persistent residual calls for a single paired intermediate, e.g. sampled texel vs post-lighting value at the first differing pixel, only if the result will distinguish two remaining mechanisms. Do not launch a campaign to fill 18/19 before resolving 15.

**Acceptance, tests and rollback.** Focus `tests.test_gfx_gl_control`, `tests.test_gfx_frame_graph`, `tests.test_m7_checkpoint_provenance` and the new selected-draw fixtures. Neighbors `tests.test_gfx_frame_trace_writer`, `tests.test_replay_blob_verifier`, `tests.test_m7_diagnosis`, `tests.test_correction_accept`. Verify missing/foreign seed, missing depth prefix, overwritten generation, unsupported GL capability, malformed mip length, source-only shader, one alpha byte and two frame IDs with ordinal 15. Run native known-good GL control first. Done when another agent can reproduce or reject the 916 control from a seal and one supported command, with three pairwise outcomes, causal limitations and an explicit 616 scope and a same-seal 904 decision. If a new capture is necessary, retain old decoded representation alongside optional sealed block data, record measured overhead and restore on every exit. Disable optional recording to roll back. A feature-specific passing fixture cannot certify full-frame parity.
