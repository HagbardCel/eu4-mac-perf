# R0 disposition and PR sequence

[Audit and acceptance](r0-audit.md) · [Evidence and migration](r0-evidence.md) · [Measurements](r0-measurements.md)

The 42 families below account for all **2,388 tracked paths, 395,033 authored physical lines, and 100,115,100 logical bytes** at the pinned tree. The selectors at the end assign each path to one family. This replaces the previous fallback of 1,331 held paths. A hold now applies to a named dependency, authority or recovery condition. Historical software can leave the active tree once a pinned Git checkout and the required evidence reproduce its result.

Pure moves count as zero. Family estimates are opportunity ranges and can overlap. Text estimates use about 40 bytes per line. Rows without a quantified opportunity carry zero credited savings. The PR budget counts assigned removals once. **Conditional** savings require proof of consumer migration or evidence recovery.
