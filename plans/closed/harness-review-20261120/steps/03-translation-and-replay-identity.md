# 03 · Bind shader caches and replays to their effective inputs

**Objective.** Reuse work across identical inputs and prevent a warm cache, overwritten stage or ambient experiment from changing the meaning of a replay.

**Evidence.** On 616, swapping attribute locations changes the translator's input and leaves `_shader_source_identity` unchanged. In `translate_stage`, two linked shaders can write the same output name. `translate_command` accepts `shaders.json` existence and stages a shared `<key>.partial`. Native `function_for` looks up file name plus entry before reading MSL. The pilot changed shader products and compiler settings across repeated invocations. None of these facts establishes that a cache hit caused the terrain defect. [Translator](../../../../automation/gfx_shader_translate.py) · [cache](../../../../automation/m6_frame.py) · [native reader](../../../../benchmark/eu4_gfx_frame_replay.mm) · [receipts](../../../../automation/gfx_independent_replay.py)

**Implementation order**

1. In `translate_trace` and `translate_live_sources`, enumerate all inputs to `translate_stage`. Construct the normalized, attribute/varying-decorated compiler source once. Give each stage a key over its stage type, actual compiler input bytes, target, relevant command flags, translator content and glslang/SPIRV-Cross tool identities. Keep original capture SHA, program and stage as provenance. Use the same computation for stage paths and the ordered program/linkage map. If a program name spans incompatible definitions within one trace, resolve by captured program state or reject that ambiguous binding.
2. Write compiler outputs under the effective key. Include output hashes, entry, reflection/bindings and link map in the manifest. Use `m6_frame.shader_receipt_identity` for the existing digest boundary. The program cache may reuse a stage when the effective stage inputs coincide. Avoid rehashing tools for every draw. Verify a cache hit before copying or publishing and validate cache/output paths before `--force`. Use a unique sibling temporary directory plus per-key publication lock or verified concurrent-winner protocol. Never replace or delete another builder's work in progress. Rebuild a missing, malformed or corrupt entry in a separate destination.
3. Audit native `function_for`, pipeline cache and reset paths across consecutive frames. Key actual MSL bytes/entry/compile options or an authenticated immutable artifact digest with equivalent binding. A diagnostic override supplying different bytes at the same name must create a new compiled function. Preserve loading of legacy frame-local shader directories for historical diagnosis, requiring verification or retranslation for new provenance claims. Introduce a new cache namespace so old hits cannot qualify silently.
4. Inventory *consumed* `EU4_FRAME_REPLAY_*` options in native and Python paths. Resolve them into an explicit recipe before replay. Attach capture, shader artifact, binary, approved options, overrides and fault state/digests to `write_producer_receipt` and the correction eligibility check. Record custom behavior as diagnostic. Reject unknown/unbound producer settings for a new qualified claim. Keep secrets, full process environment, absolute host-specific paths and proprietary source out of public manifests. Test default vs explicit default canonicalization. If the optional recipe is absent on a historical result, expose the limitation.

**Verification.** Focus `tests.test_m7_translation_cache`, `tests.test_m6_frame`, `tests.test_m7_shadow_receipt`; then `tests.test_m7_evidence_identity`, `tests.test_correction_accept`, `tests.test_m7_continuous_replay`. Use the runner in the roadmap. Include two programs sharing raw stage bytes with swapped attributes, different linked varyings, byte-identical inputs in different frames, changed translator bytes with preserved size/time, different tool/flag, stale output, two same-key publishers and an interrupted publisher. Compare cold/warm manifests, compiled bindings and pixels in a colored-vertex fixture. Exercise sequential override/default replays and reject a mutated recipe on recomputation.

**Done and rollback.** Every tested change to a consumed input invalidates the corresponding cache or receipt, identical inputs reuse the result, and independent readers cannot observe half a publication. Record one cold/warm timing, keeping compilation and verification separate. Existing sealed cases still diagnose. Roll back by disabling shared cache reads and translating into isolated per-run directories while retaining new receipts. No migration of all historical caches is necessary.
