# 04 · Encode the captured sampler and raster state faithfully

**Objective.** Correct demonstrated descriptor aliasing and raster-state mappings with GL/Metal controls small enough to run without EU4. Acceptance for these cases is distinct from acceptance of any terrain change.

**Evidence.** Present 616 exercises six different max LODs on one native sampler cache key. In the reviewed encoder any enabled face culling selects `MTLCullModeBack`. A negative viewport origin passes through an unsigned integer, and clipping a scissor origin without its far endpoint enlarges its coverage. Full-viewport terrain is a poor detector of these errors. Existing state-coverage labels are also too coarse to distinguish an implemented enum from another unsupported value. [Encoder and descriptor construction](../../../../benchmark/eu4_gfx_frame_replay.mm) · [coverage](../../../../automation/gfx_independent_replay.py) · [fixture suite](../../../../tests/test_m7_metal_replay.py)

**Implementation order**

1. Freeze two minimal draw packets using the existing fixtures and native host. For the sampler, use two differently colored mips with identical S/T/filter inputs but different effective max LODs, then reverse submission order. Use a comparison-enabled depth texture where supported. Record the GL outcome, target generation and selected texels. Include a second fixture for a front/back winding pair and signed partial scissor. Keep bytes game independent.
2. At descriptor creation derive a value identity from precisely the resolved properties used by Metal, including R, compare mode/function and LOD clamps. Preserve explicit defaults and map float and enum values without truncation. Include all sampling semantics applied outside the descriptor (e.g. bias) at the stage that actually consumes them. Ensure sampler lookup and creation have one owner. Reject unsupported active values with slot/event evidence. Separate GL base/max mip levels on a texture from sampler LOD clamps. Verify handling of incomplete mip chains before extending supported states.
3. Decode cull enable, cull face and captured front winding relative to the existing framebuffer/Y convention. Test both windings and both face selections. GL front-and-back cull on applicable primitives must produce the appropriate no-fragment outcome or an explicit unsupported result. For signed scissor compute the intersection from signed near/far endpoints with safe arithmetic, then convert to Metal coordinates once. An empty intersection must draw no fragments and must preserve subsequent draws. Keep signed/float viewport origin and depth range. Verify behavior of out-of-range inputs on the supported device before claiming coverage.
4. Project supported, explicitly rejected and unobserved state consistently through the native receipt and `state_coverage`. Preserve the current diagnosis for dither, samples, depth/stencil, unsupported blend/format combinations and sRGB until separately measured. Verify the neighboring depth compare/write, independent alpha, color write mask, flipped target and target resize controls across an encoder break. Scope implementation to the states demonstrated above.
5. Run the existing reconstruction campaign with the OpenGL–Metal skill and independent checker for the cohesive renderer changes, or use the authorized native DSH goal under the project exception. Use one commit/candidate per separable state family. Record a cold reference baseline and before/after from the same sealed case. Exact earlier checkpoints and a protected known-good case are mandatory for promoting any authentic correction.

**Verification and done.** Focus `tests.test_m7_metal_replay` and `tests.test_m6_frame`; then `tests.test_m7_target_lifetime`, `tests.test_m7_continuous_replay`, `tests.test_m7_diagnosis`. Check two submission orders, unequal sampler states, disabled comparison, negative and fully outside scissor, nonzero viewport, all winding combinations, zero raster coverage and a subsequent unrestricted draw. Require exact GL-vs-Metal results for each claimed supported fixture. A hardware-unavailable run must identify its skip. Replaying 616 may legitimately leave event 15 unresolved. Record the outcome and any unexpected change, with producer and case IDs. Roll back each mapping independently if an earlier exact control regresses; retain the failing fixture and unsupported-state diagnosis.
