**Evidence.** In .local/m7/goal-round1/capture, file mtimes in UTC order are startup.status 21:43:46.448, frame-seal.json 21:44:16.257, shadow-report.json 21:44:22.053, shadow/case/case.json 21:44:30.968, shadow/coordinator.json 21:44:30.969, operations-summary.json 21:47:52.352 and launcher-report.json 21:47:53.449. The operations recorder reports 7,907,907 observations, last_event_ms=240003, events=0, records_copied=false and integrity_ok=false. This ancillary recorder did not supply the authoritative 325-event sealed stream. The launcher reports accepted=false for its own ops contract. Do not report an accepted ops trace. The 202.48 s gap is a single-case opportunity including cleanup, not measured savings on a revised launcher.

1. In automation/m6_frame.py where continuous capture starts the coordinator and calls startup.run_ops, explicitly select a completion policy for this consumer. Extend benchmark/eu4_gfx_startup_trace.py run_ops/_wait_pair with an optional terminal check or equivalent narrow interface. Default remains the existing summary+ops pair. Pass the freshly created run directory, owned process/session, frame policy, coordinator handle and deadline. Avoid another watcher process.
2. Reuse the coordinator's terminal decision after all requested frame/shadow/case artifacts are closed. Prefer child exit + parseable final report and validate its linkage to the current sealed frame/session/pid/digests. Use an atomic publication boundary if a reader can race the writer. Do not stop merely because the first seal, GPU command, stale file, partial JSON or intermediate frame exists. Preserve multiframe capture, fail-closed health stops, readiness timeout and the coordinator's own failure classification. If the coordinator exits without a valid terminal result, return structured instrumentation failure and reap both owned processes.
3. Keep the same lease, one-use claim and finally block for process termination, settings restoration, stdout/stderr close and display restoration. Report explicit stop reason, timestamps and independent statuses for requested capture and optional operations recorder. Missing post-stop auxiliary output must not look like a passing operations trace. Clients requiring full ops acquisition continue using the old policy.
4. Use an injected clock, fake game and coordinator with staged files. Advance beyond a ready terminal result while leaving ops summary absent. Assert bounded return within the poll interval plus cleanup, correct terminal classification and restored resources. Cover early seal, late frame in multi-frame mode, stale/foreign receipt, child death, concurrent file publication, timeout and GPU failure. In normal mode require both original summaries. Native producers need no additional GPU readback.

Run focused tests.test_gfx_startup_trace and tests.test_m7_continuous_supervisor, then tests.test_m6_frame, tests.test_m7_continuous_coordinator, tests.test_campaign_guard and tests.test_dsh_launch_safety.
