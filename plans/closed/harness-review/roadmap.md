## Release decisions

1. **Before the next authentic investigation**, record the baseline with dsh_efficiency, verify/pin 616 and its control, land the new checker negatives, and run the campaign-entry smoke with zero launches. The current sealed case is sufficient for localization. If pin verification fails, stop on the named missing artifact.
2. **Before changing renderer policy**, use the independent state fixture to prove the sampler mapping and its bounds. Use scoped offline replays with variant identity and an explicit negative control. Correction acceptance must verify every required control on the candidate producer. If a hypothesis fails, preserve the tested inputs and measured result; do not promote an alternate hypothesis without testing it.
3. **After the short path works**, compare fixed-task trials per Step 06; only pursue CI restructuring, new observation points or additional graphics-state families when a reproducible stall or failing fixture pays for them. Publish canonical facts and dated limits in Step 07. An increase in accepted corrections per hour is credible only with the stronger checker held fixed across both benchmark arms.

## Shared verification contract for the steps

From the pinned candidate worktree, replace module arguments below with the focused modules in the relevant step. Then run its named neighbors. Use the checked interpreter and the existing duplicate-aware runner. For a failure, repeat the same selection using --cwd in a base worktree and compare run records. Run the full offline gate once at the end of each implementation change set. This review changes documents only.

```sh
python3.14 -m automation.python_runtime resolve
python3.14 -m automation.test_runner run --profile offline --module tests.test_correction_accept
python3.14 -m automation.test_runner run --profile offline --module tests.test_m7_diagnosis --module tests.test_m7_checkpoint_provenance
python3.14 -m automation.test_runner compare --base <base-id> --candidate <candidate-id>
python3.14 -m automation.test_runner run --profile offline --label full
```

Use a real macOS host for GPU fixtures and record skips. The live profile is explicit and bounded; checker pass and an independent PR review are distinct gates. Maintain exact BGRA and authoritative checkpoint requirements throughout. None of the steps calls for a global renderer rewrite, a generic graphics platform or a second scheduler.
