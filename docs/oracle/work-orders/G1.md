# G1 — second-function RE0 and package boundary

## Deliverable

A second-function selection and RE0 characterization that passes the existing
RE0→RE1 gate, plus the documented function-package boundary.

The package must record:

- the pinned function identity, binary/build pins and address ranges;
- the RE0 contract: preconditions, postconditions, modified memory, calls, ordering
  constraints and unobserved/uncertain cases;
- the object-layout table, dependency map and caller/thread/context assumptions;
- the fixture plan and the declared evidence tier;
- the harness and per-function replay-adapter plan;
- explicit limits and a list of what is not established.

Selection must follow the existing RE0 gate, not a pre-committed symbol. The current
ranked candidates include `InternalSetTextureAndSamplerState`, `GfxDrawIndexed` and
a nearby Gfx setter, but the gate decides.

## Required checks

- Every static claim is tied to the pinned binary, address or reviewed P-code run.
- The selected function has a recoverable input/side-effect surface and a credible
  independent-reference strategy.
- No unresolved ownership, context or aliasing requirement makes a faithful
  replacement unsafe.
- The package boundary is documented without inventing a generic schema.
- The decision to add a small per-function A2 closure branch, or to reuse the
  existing one, is recorded explicitly.
- The package names the replay-adapter work G2 must complete; it does not claim that
  `oracle.function.replay` already supports the function.

## Non-goals

- No RE1 source reconstruction, no Emulation/replay adapter implementation and no
  live acquisition.
- No generalization of A2, PR C or the recorder schema.
- No agent adapter changes, held-out material or live game evidence.
- No generic multi-function package schema.

## Stopping rules

- **Contract conflict:** if the selected function cannot be expressed by the
  existing package boundary, propose a focused amendment.
- **Scope expansion:** if the function needs an unbounded object graph, general
  memory tracing or a new recorder, stop.
- **Evidence limitation:** if static evidence is unavailable, document the gap and
  do not advance the function to RE1.

## Merge gate

The RE0 contract is reviewed against the pinned binary, the package boundary is
recorded, and the RE0→RE1 gate is explicitly passed or failed with reasons.
