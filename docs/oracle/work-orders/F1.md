# F1 — offline shadow worker

## Deliverable

An isolated worker that accepts an owned snapshot, executes the frozen candidate
through the existing restoration/replay path, and publishes a bounded result with
exact accounting. A supervisor enforces the deadline, output cap, queue capacity
and failure isolation.

The worker must:

- receive an owned copy of one `FUNCTION-CAPTURE v1` transcript and the frozen
  candidate/harness identity; never receive a live game pointer or the original
  session directory;
- call the existing replay/comparator path rather than reimplementing comparison;
- classify worker outcomes as completed, timeout, crash, refused or dropped, and
  keep infrastructure failure distinct from candidate mismatch;
- preserve deterministic verdicts for identical snapshots and candidate identities;
- write only inside its own work directory;
- account for every accepted, completed, refused, timed-out, crashed and dropped
  snapshot.

## Required tests

- malformed snapshot, missing descriptor input and unsupported function;
- worker crash, timeout, output-cap violation and queue exhaustion;
- delayed processing and duplicate snapshot submission;
- deterministic result for identical inputs;
- no writes outside the worker directory;
- a simulated worker failure cannot change the producer's result or block its
  completion;
- accounting totals reconcile exactly.

## Non-goals

- No live game integration, live pointer access or PR D session coupling.
- No new comparator, capture path, schema or quota change.
- No sandbox guarantee; this is the same application-level boundary as P3.
- No F2 sampling campaign or live throughput design.

## Stopping rules

- **Contract conflict:** if the snapshot handoff cannot express an owned copy
  without exposing the original session, propose an amendment.
- **Scope expansion:** if a new transport, sandbox or comparator is required, stop
  for an architectural decision.
- **Evidence limitation:** complete the synthetic worker path and report live
  integration as blocked.

## Merge gate

The worker and supervisor pass the offline contract tests, all failure classes are
attributed, and review confirms the worker has no live-game authority.
